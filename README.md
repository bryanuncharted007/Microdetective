# Microdetectives V3

Juego educativo sobre microorganismos, uso responsable de antibióticos y resistencia bacteriana, crucigramas, sopa de letras y duelos QR.

## Demo gratuita
El archivo `render.yaml` describe una demo sin cobros. **Los puntos NO persisten tras reinicios o redeploys de Render**, por eso el canje de premios se desactiva con `MICRO_DEMO_ONLY=1`. No utilizar para premios reales.

## Evento real
`render-paid.yaml` muestra una configuración con disco persistente y plan de pago, que requiere aprobación del propietario. Configurar `MICRO_ADMIN_KEY` como secreto solo en Render.

## Seguridad
El repositorio es público; los bancos de preguntas pueden leerse desde el código. No depender únicamente de la repetición limitada de puntos para premios valiosos.
